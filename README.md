# 🌙 Moonly — Emotional Support AI

> **让每一个孤独的深夜，都有人陪伴**

Moonly 是一款面向海外市场的 AI 情感陪伴工具，专注于单身男女的日常情绪疏导。

## 🎯 产品定位

**一句话描述**：一个随时在线、AI 驱动的情感陪伴伙伴，帮助用户度过孤独、焦虑、失眠的时刻。

**差异化定位**：比 Replika 更温暖、比 Character.AI 更聚焦情感支持、专为日韩欧美市场打造。

## 🌐 目标市场

- **Primary**: 美国、英国（英语市场，高付费意愿）
- **Secondary**: 日本、韩国（高需求、文化契合）
- **Tertiary**: 东南亚（增长潜力）

## 💡 核心功能规划

1. **AI 即时聊天** — 7x24 小时情感陪伴
2. **情绪打卡** — 每日心情追踪 + AI 解读
3. **记忆功能** — AI 记住用户故事，个性化对话
